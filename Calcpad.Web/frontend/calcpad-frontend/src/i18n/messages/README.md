# Shared UI catalogs

- `en.ts` is the English source.
  Keys are the English text, so the file is intentionally empty.
- A locale catalog is `<locale>.ts`, with `provenance.<locale>.json`.
  `zh.ts` is community-authored; the translated catalogs other than `zh.ts` are generated.
- `sources.json` declares the shared source labels and the VS Code pack pin.
- The locale list lives in `../locales.json`; the script generates
  `../locales.generated.ts` from it.
- `cs.ts`, `de.ts`, `es.ts`, `fr.ts`, `it.ts`, `ja.ts`, `ko.ts`, `pl.ts`,
  `pt-BR.ts`, `ru.ts`, `tr.ts`, and `zh-Hant.ts` are generated by
  `scripts/i18n/i18n.mjs`.
  It rewrites generated `vscode` entries and preserves entries marked
  `community`.
  Their provenance is updated alongside them.
- `zh.ts` is not generated.
  Its Monaco map still comes from `vscode-language-pack-zh-hans`.
- The generator reads `scripts/i18n/data/vscode.index.json` (English to VS Code module/key)
  and `scripts/i18n/data/vscode.langpack.<locale>.json` (pinned pack subset).
  A word can have several pack translations because it appears in different modules.
  The importer imports only unique single translations; multi-variant keys stay
  English until the community decides. See `TRANSLATING.md`.
- Community overrides use `source: "community"` and `replaces: "vscode"`.
  The importer preserves community entries; only their human review workflow is still being defined.
- Keys missing from a catalog fall back to English.
- `provenance.<locale>.json` records each key's source and origin; there is no default.
- A community entry is `{ source: "community", origin: "<commit>" }`.
  `origin` is the short commit that last changed the translation.
- A `vscode` entry is copied from the pinned VS Code pack.
  It records `vscodeSource`: `vscode-monaco` or `vscode-shared-ui`.
  The label covers any shared Calcpad UI surface, not only Vue.
- `vscodeMatch: true` flags an exact English + translation match with the pack.
  It is an observation, not proof of copying.
- A community entry can add `replaces` when it supersedes a `vscode` string.
- Native Tauri menu labels live in the same catalogs.
  `i18n/menu.ts` lists the keys and filters untranslated entries.
- `Auto` is looked up as `tt('Auto')`; each catalog can add its own reviewed entry.
  It resolves the current culture first, then the host language, then the browser list;
  a culture without a catalog falls back to English.
- Add new `zh.ts` keys with explicit provenance in `provenance.zh.json`.
