    Linter and Diagnostics¶

    CalcpadCE checks your document as you write and flags problems before you ever run it. Each diagnostic has a short, stable code (like CPD-3301) so you can look up exactly what it means.

    Diagnostics appear as squiggles in the editor and entries in the Problems panel.

    Where diagnostics come from¶

    • As you type, the linter checks the document without running it, including #include and #def errors and code in branches and loops that don't run.
    • When the preview runs the document's calculation errors also appear in the Problems panel.

    Suppressing diagnostics (lint-ignore)¶

    To silence specific diagnostics in a section, wrap it in LintIgnore / EndLintIgnore markers and list the codes to ignore:

    '<!--{"LintIgnore": ["CPD-3301"]}-->
prototype_var = 5
'<!--{"EndLintIgnore": []}-->

    Leave the list empty ("LintIgnore": []) to suppress all diagnostics inside the region.

    These markers are one kind of metadata comment; the Properties panel tab can write them for you with a code picker.

    Choosing how much to show¶

    The Minimum Severity setting hides diagnostics below the level you choose. Set it to warning to see only warnings and errors, or error for errors alone.
